# Nametag Coding Challenge

Write a program that updates itself. Imagine you've deployed a program to clients and will
periodically ship new versions. When a new version is produced, we want the deployed
programs to be seamlessly replaced by the newer one.
Please write what you consider to be production-quality code — whatever that means to you.
Use any common programming language you're comfortable with. Your program should
reasonably be expected to work across common desktop operating systems (Windows, Mac,
and Linux). If your scheme requires non-trivial server components, please write those as well.
